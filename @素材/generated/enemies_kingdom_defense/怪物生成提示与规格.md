### 图集切图规则

每张图集为 `16 列 x 4 行`。

每 4 列是一种怪物：

1. 待机
2. 移动 1
3. 移动 2
4. 攻击

4 行方向顺序：

1. 下
2. 左
3. 右
4. 上

也就是：第 1 个怪物使用第 0-3 列，第 2 个怪物使用第 4-7 列，第 3 个怪物使用第 8-11 列，第 4 个怪物使用第 12-15 列。

## 本轮使用的核心提示词结构

普通怪物正式规格提示：

```text
Use case: stylized-concept
Asset type: Godot 2D monster directional animation atlas
Primary request: create a transparent pixel-art monster atlas with 4 enemy types, each enemy has down/left/right/up views and attack frames
Composition/framing: exact grid concept 16 columns x 4 rows. Each enemy occupies 4 adjacent columns. Rows from top to bottom are down, left, right, up. For each enemy, its 4 columns are idle, walk1, walk2, attack. Center one full-body enemy per cell. No labels.
Constraints: transparent background, no text, no watermark, no terrain, no UI, attack frame must face same row direction
Avoid: cropped limbs, extra characters in a cell, labels, background panels
```

Boss 草案提示：

```text
Use case: stylized-concept
Asset type: Godot 2D seasonal boss sprite and skill atlas
Primary request: transparent pixel-art atlas for a seasonal boss, larger than normal enemies, with two extra skill effect designs
Composition/framing: top row 4 large boss frames, bottom row 2 separate larger skill effect designs with empty spacing; no text labels
Constraints: transparent background, boss visibly larger than normal enemies, no text, no watermark, no terrain, no UI frame
```

## 下一步：Boss 弹幕生成规格

下一步优先生成 Boss 弹幕与技能贴图，不先接逻辑。

目标：

- 每个四季 Boss 设计 4 种弹幕/技能。
- 每种技能需要有“动态感强”的贴图草案，可用于后续做动画序列。
- 每个技能至少包含：预警范围、飞行弹体或爆发主体、命中/溅射效果。
- 需要明确是否有溅射伤害、持续伤害、击退、减速、治疗或召唤。

建议每个 Boss 四种技能：

### 春季 Boss

1. 根刺连环：地面多段预警后长出藤刺，直线溅射伤害。
2. 花粉环爆：圆形花粉扩散，范围内敌方回血，殖民者减速。
3. 藤蔓缠绕弹：追踪藤球，命中后小范围束缚。
4. 召唤春芽：召唤春藤小怪，落点有绿色光圈。

### 夏季 Boss

1. 熔火吐息：扇形火焰弹幕，持续灼烧。
2. 陨火雨：多个圆形落点预警，落地溅射。
3. 火环冲锋：Boss 冲锋留下火焰路径。
4. 熔岩炸弹：慢速大火球，命中后分裂小火星。

### 秋季 Boss

1. 叶刃旋风：旋转叶刃环绕飞行，穿透伤害。
2. 南瓜恐惧灯：范围恐惧/混乱，地面橙色预警。
3. 稻草人分身：召唤稻草傀儡，死亡爆叶。
4. 收割镰波：半月形弹幕，多段溅射。

### 冬季 Boss

1. 冰刺牢笼：圆形冰刺围困，落点预警后爆发。
2. 暴风雪锥波：锥形减速弹幕，持续寒冷伤害。
3. 冰晶散射：多方向冰晶弹，命中小范围溅射。
4. 霜冻践踏：近战范围冲击波，击退并减速。

```text
Constraints: transparent background, no text, no watermark, no terrain, no UI frame, strong motion trails, clear damage radius, visually distinct skills
Avoid: characters, background panels, unreadable particles, cropped effects
```
