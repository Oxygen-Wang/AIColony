## 六、与代码的差异（改代码时的对齐清单）

> 设计以本表为准，代码侧现状如下，落地时改到一致。

| 项目 | 代码现状 | 设计值 |
| --- | --- | --- |
| 城墙费用 | `COSTS` wall = 木2 | 石5 |
| 木门费用 | door = 木4 | 木6 |
| 床费用 | bed = 木5 | 木8 |
| 火把费用 | torch = 木1 | 木3 |
| 篝火费用 | campfire = 木4石2 | 木10 |
| 农田费用 | farm_plot = 木2 | 木4 |
| 炮塔建筑体 | `COSTS` turret = 铁8石8（与 defense 研究费撞车，疑混淆） | 石20铁12；研究费铁8石8另付 |
| 铜/铀资源 | `resources` 无 copper/uranium；`VALID_TARGETS` 无铜铀 | 新增资源、采集目标、库存、HUD、地形生成 |
| craft 种类 | `VALID_ITEMS` 仅木剑/石斧 | 木/石/铁三档工具全进 + 制造门（科技+台子） |
| 采集门槛 | 无门槛，有斧仅加速 | 无木镐不动石、无石镐不动铁铜、无铁镐不动铀 |
| 制造门 | craft 不查台子不查位置 | 按科技表锁，木镐/木斧/木箭徒手可搓除外 |
| 新建筑物块 | 只有旧 18 种 | 分批进 `T` 枚举（贴图先复用铁矿/石块，后补） |
