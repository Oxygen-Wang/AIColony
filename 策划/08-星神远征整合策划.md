# AI Life：星神远征 · 整合策划

更新：2026-09-17。主项目为 `AIColonyDemo`。本文取代早期“五夜生存、纯文字建造”方案；历史文档保留作设计来源。以项目现状为基础，明确区分本轮实现与下一阶段设计。

## 1. 核心体验

玩家扮演方舟的决策者，通过舰载总管“星神”把自然语言变成殖民者的工作。玩家决定基地长什么样，殖民者负责把它建出来，并维护既有生产设施。

核心循环：观察资源与威胁 → 手工规划建筑 → 文字分配采集、施工、生产或防卫 → 研究新设施 → 携带基地迁移到下一颗星球。

玩家持续面对三个选择：现在投入生存还是科技、让谁承担外出风险、何时结束积累启程。地图规模与科技数量都为这些选择服务。

## 2. 本轮实现的可玩范围

| 系统 | 当前规则 |
|---|---|
| 世界 | 128×128 格，32 像素；森林、石料、铁矿、地表洞穴；每昼夜 600 游戏秒 |
| 人员 | 抽抽、班花、龟龟、魔法师、七海、鱼和糖；六个可辨识精灵，五项工作能力 |
| 决策 | 自然语言指令，支持分句人物与数量、“然后”继承人物；不填 Key 可离线玩 |
| 规划 | 左键放蓝图，Ctrl+左键拖动连续规划，右键撤销；永久建筑由玩家选址 |
| 自主性 | 生存需求、近身反击、既有农田补种/收割、食物不足时烹饪、施工与维修 |
| 科技 | 镐子锁矿→工作台→石镐挖铁铜→研究台→自动火力→蒸汽→电气→核能；详见科技树-物品链.md |
| 胜利 | 建成行星发动机、清除野兽，迁移到新地图后结算 |
| 继续 | 结算后继续殖民；建筑、建筑损伤、库存、作物、蓝图、科技和幸存者状态保留 |
| 失败 | 全体殖民者死亡，允许重新开始 |

“迁移”本轮采用整张地图内人工建设随船保留的简化规则，地图自然资源重新生成。还没有连通地基检查、迁移动画和目的地环境差异。

## 3. 首局引导与信息反馈

开局应先看懂六个人、库存和当前目标，不要求先读完整策划。推荐路线：

1. 输入“抽抽砍5棵树，七海采3块石头”，看到两人执行不同任务。
2. 规划床与农田；殖民者会自动施工，农田建成后进入维护循环。
3. 安排铁矿采集，规划研究台。顶部目标提示随后切换到科技阶段。
4. 白天投入建设与科研，夜间安排迎击或撤退，利用墙、门和炮塔防御。
5. 完成自动火力与蒸汽电气核能研究，建成行星发动机，清场后启程。

界面提供当前目标、资源、六人状态、研究进度、蓝图材料提示、快捷示例与指令历史。饥饿和疲劳越低越好，心情越高越好；悬停人物卡查看能力与待办数量。

命令反馈分两层：星神解释理解出的工作，执行层报告是否实际派发。未规划建筑时明确提示先放蓝图，不让玩家误以为已经开工。撤退、迎击、停工清除旧工作并立即处理。

## 4. 建造与自主工作边界

玩家拥有永久建筑的选址权。AI 只施工已有蓝图，不能自行围墙、铺地或改变基地轮廓。施工完成时再次确认蓝图仍然有效，取消后不得扣款或生成建筑。

默认施工只派一人，避免多人争同一份材料。食物维护也采用单人调度，减少同时抢收同一株作物或争用最后一份原料。玩家仍可显式指派多人劳动。

自主播种只维护已建农田；明确下达“种地”时保留现有野外种植能力。后续可把野外种植统一收敛为农田规划，避免两套种植语义长期并存。

## 5. AI 的职责与容错

动作表是执行边界。大模型仅返回文字说明与命令，不能直接写资源、生命、科技或地图。最多处理八条命令，每条数量限制在 1～99。

无 Key 使用规则解析；网络或响应异常时按玩家原话兜底。不能根据模型的道歉或建议文本反推工作，防止执行玩家没有要求的动作。JSON 提取借鉴旧项目的字符串识别与括号配平，允许前后有说明文字。

本轮不接入持久记忆、每帧模型推理和自动长期规划。实时生存与生产仍由确定性游戏逻辑负责。

## 6. 下一阶段优先级

### P1：让迁移成为真正的经营决策

定义连通方舟地基，只有连通区域内建筑随船迁移。跃迁前显示“携带/遗留”的明确清单。新增能源储备、导航、生命维持的最低要求，并在界面逐项显示缺口。完成之前不得把装饰性发电机、电池当成已经实现的电网。

### P1：补齐可长期玩的可靠性

存档/读档保存地图种子、变更格子、人员、科技与生产状态。夜袭需保证出生点能进入战区；封闭防线时选择可攻击的墙体路径。长时平衡验证至少覆盖五昼夜、一次完整科研迁移、断粮、全灭和恢复。

### P2：星球差异与人物故事

新星球先只选一种压力：低温增加能耗、贫瘠减慢作物、强磁暴限制自动火力。选择必须改变布局或资源配置，而不只是改变地图颜色。人物隐藏性格通过可读事件体现，避免只有标签而没有行为。

### P2：听觉与演出

旧项目的环境音、建造音、采集音、指令确认音已迁入资源库。本轮未全面接线。后续按事件添加有限并发、音量控制和冷却，避免六人同时劳动造成声音堆叠。方舟升空动画在迁移数据可靠后再制作。

## 7. 素材与维护规则

采用旧项目验证过的 VX Ace 角色块索引与树石/建筑图块区域，32 像素、最近邻采样。新科幻设施暂保留程序绘制，以免拿含义不符的图块误导玩家。

`script/` 放游戏逻辑，`scene/` 放场景，`image/` 放图片，`audio/` 放声音，`test/` 放回归检查。参考图集附属场景也放 `scene/reference/`。没有引入新的框架依赖。

旧项目的授权文件随素材保留；只有 autotiles 附带 CC0 说明，不能由此推断其他素材也是 CC0。发布前应核对各原始素材包的授权来源。
