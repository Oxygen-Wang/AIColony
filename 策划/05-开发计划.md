# 05 · 开发计划

## 目录结构

```
ColonySim/
├── project.godot
├── icon.svg
├── README.md                 # 运行 / 操作 / 玩法说明
├── deepseek_key.txt          # 可选，放 API Key（已在 .gitignore 里）
├── .gitignore
├── scenes/
│   └── main.tscn             # 唯一场景，仅挂 Main 脚本
└── scripts/
    ├── main.gd               # 根节点：装配世界/UI/循环
    ├── game_state.gd         # 全局状态单例：时间、库存、天数、胜负
    ├── terrain.gd            # 地形枚举 + 地图生成 + 格子 BFS 寻路
    ├── world.gd              # 地形烘图渲染 + 建筑渲染 + 格子查询
    ├── night_overlay.gd      # 夜晚遮罩 + 光源柔光
    ├── pawn.gd               # 小人：数值、移动、干活、战斗
    ├── beast.gd              # 野兽
    ├── building.gd           # 建筑（墙/门/床/炮塔/农田…）
    ├── task_system.gd        # 任务队列与派活
    ├── actions.gd            # 28 个动作定义（唯一真相来源）
    ├── ai_bridge.gd          # DeepSeek 调用 + 世界快照 + 提示词 + JSON 抢救
    ├── fallback_parser.gd    # 规则兜底解析
    ├── selftest.gd           # 无头自检
    ├── fonts.gd              # 中文字体加载（系统字体兜底）
    └── ui/
        ├── chat_ui.gd        # 聊天框
        └── hud.gd            # 顶栏 + 侧栏 + 结算面板 + 设置
```

比原计划多出三个文件，都是实现过程中必要的补充：

- `night_overlay.gd` —— 原计划把昼夜遮罩塞进 world.gd，但遮罩必须盖在小人之上、UI 之下，独立节点最干净
- `fonts.gd` —— Godot 默认字体没有 CJK 字形，不加载系统字体中文全是方块
- `selftest.gd` —— 无头自检，把"打字→派活→小人真去干"这条核心链路变成可回归的测试

## 里程碑

| # | 内容 | 验收 |
|---|---|---|
| M1 | 项目骨架 + 地图生成 + 相机 | 能跑起来，看到 128×128 彩色地图，能平移缩放 |

| M5 | 昼夜 + 野兽夜袭 + 建造防御 | 第 1 夜有野兽来，小人能打死它 |

## 关键技术风险与对策

| 风险 | 对策 |
|---|---|
| DeepSeek 返回非法 JSON | 正则抠 `{...}` + 规则兜底，永不崩 |
| 没有 API Key | 直接走兜底解析，Demo 照样可玩 |
| 128×128 逐格节点卡死 | 地形烘成一张 ImageTexture，单 Sprite2D |
| 寻路每帧重算 | 格子 BFS，目标变化时才重算 |
| .tscn 手写易错 | 场景只留一个根节点，UI 全代码构建 |
| 中文显示 | 用系统字体 `C:/Windows/Fonts/msyh.ttc` 兜底 |

## 执行顺序

按 M1→M6 顺序一次性实现，最后统一跑通验收：

1. `project.godot` + 目录
2. `terrain.gd` → `world.gd` → `main.gd`（M1）
3. `game_state.gd` → `pawn.gd`（M2）
4. `actions.gd` → `building.gd` → `task_system.gd`（M3）
5. `ai_bridge.gd` → `fallback_parser.gd` → `ui/chat_ui.gd`（M4）
6. `beast.gd` + 昼夜 + `ui/hud.gd`（M5/M6）

## Demo 交付标准

- 双击 `project.godot` 或用 Godot 打开即运行
- 不填 API Key 也能完整玩通 5 天（走兜底解析）
- 填了 Key 则享受自然语言派活
- 1080p 窗口，纯色块画面，无崩溃
