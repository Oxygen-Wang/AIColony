# 04 · 游戏内容

## 地图

**极简算法生成**，128×128 格，每格 16 世界像素。

生成步骤：

1. 两层 FastNoiseLite 叠加 → 高度场 → 阈值切出 **草地 / 泥土 / 水**
2. 第二层噪声 → **石山**（成片，可挖）
3. 石山内部再叠噪声 → **铁矿脉**（稀，嵌在石山里）
4. 石山边缘抠出 **3~5 条洞穴**（短隧道，通向山体内的空腔）
5. 草地上按密度撒 **树**
6. 出生点：地图中央附近找一块 ≥12×12 的无水草地，作为初始营地

各自带：

- 性格标签（勤快 / 懒散 / 莽撞 / 胆小 / 心细 / 结实）—— 影响数值衰减速度与干活速度
- 属性：工作速度、战斗、体质
- 状态数值：`hunger` `fatigue` `mood` `hp`，全部 0~100

**数值驱动自主行为（纯代码）**

| 条件 | 自主行为 |
|---|---|
| hunger < 25 | 中断当前任务 → 找食物吃 |
| fatigue < 20 | 中断当前任务 → 找床睡（没床就地睡，恢复减半） |
| mood < 15 | 停手发呆，工作效率减半 |
| 夜间且附近有野兽 | 自动转为迎战 |

AI 只是**读取**这些数字来生成台词和派活，永远不直接写。

## 威胁：夜袭野兽

- **昼夜循环**：一天 = 3 分钟真实时间（1x 速度下），昼 2 分钟 / 夜 1 分钟
- **白天**：地图安静，专心种田造房
- **入夜**：从地图边缘随机生成野兽波次，向营地推进

| 夜 | 数量 | 血量 | 攻击 |
|---|---|---|---|
| 第 1 夜 | 2 | 30 | 4 |
| 第 2 夜 | 3 | 35 | 5 |
| 第 3 夜 | 5 | 40 | 6 |
| 第 4 夜 | 7 | 45 | 7 |
| 第 5 夜（大袭击） | 12 | 55 | 9 |

野兽 AI：寻最近可达目标 → 撞墙则拆墙 → 攻击小人。被炮塔/小人反击会掉血。

## 昼夜与光照

夜晚整张地图叠一层深蓝半透明遮罩（`Color(0.05, 0.08, 0.2, 0.55)`）。
营火/火把在遮罩上挖出柔光圆（用 `PointLight2D` 或简单的半透明圆叠加）。

## 结算

- **通关**：第 5 夜最后一只野兽死亡且仍有小人存活 → 胜利面板
- **失败**：小人全灭 → 失败面板，显示存活天数

## 美术

**2026-09-16 改版**：原计划是"纯色块 + 简单形状，零素材依赖"，实做后改为**地面保留色块、其余全用 RPGMaker VX Ace 素材**。

| 对象 | 方案 |
|---|---|
| 地面（草/泥/沙/水/洞） | 色块，整图烘焙成一张 `ImageTexture`（8× 采样 + 格边描边） |
| 树 / 石山 / 铁矿 | `Outside_B` 物件图，32px 1:1 |
| 建筑 | `Outside_B` / `Inside_B` 图块，`crop` 按生长度调色 |
| 小人 / 野兽 | VX Ace 标准行走图，4 方向 × 3 帧 |
| 头顶状态条 / 名字 / 动作 | 仍是代码绘制（UI 不该跟着相机缩放） |

选这条路线的原因是：地形是程序生成的，接素材要走 autotile 规则、收益低；而人物和物件数量有限、贴图收益最高。

`Terrain.TILE` 从 16 提到 **32**（素材原生尺寸），所有像素距离常量同步 ×2。

UI 用 Godot 默认主题 + 少量 `StyleBoxFlat` 调色即可。
