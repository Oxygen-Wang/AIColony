## 七、武器升级线（汇总）

1. 徒手期：木矛/木弓/木剑，便宜，守前两夜。
2. 台1级：石剑配木盾 + 精木弓，攻守兼备。
3. 台2级：铁剑盾 + 铁弓铁箭，最强单兵。
4. 科技火力：炮塔（自动火力解锁），夜里自动打兽。
5. 电气：激光炮塔（铁8铜6），强但耗电，守大波次。

弓箭线全程不断：木弓 → 精木弓 → 铁弓铁箭，和剑盾线平行升级。

## 九、研究台与科技（12 节点；食物线为侧支不卡主线）

- 研究台：木10铁4，铁必须石镐挖来；铁器时代起研究需先建成它，木器/石器免台（见[科技树.md](科技树.md)第四节）。
- 主线：woodcraft → stone_age → iron_age（前置 stone_age）→ 自动火力 defense → 蒸汽 steam → 电气 electric → 核能跃迁 nuclear。
- 侧支：stone_age 之后可点驯化种田 farming（木6）→ 浅滩钓鱼 / 围栏放牧 → 食物链整合（双前置）→ 收纳物流 logistics（解锁收纳箱木8石4、医疗舱木10铁4），只加成不卡主线。
- defense 研究费铁8石8；炮塔建筑体石20铁12另付（代码侧两者撞车待拆分，见资源表第六节）。
