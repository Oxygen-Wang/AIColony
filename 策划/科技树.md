# 科技树（按资源表重设计版，2026-09-17）

> 设计总线：MC/泰拉式**镐子锁矿** + 工作台等级 + 异星工厂式**蒸汽→电气→核能**攀升。

## 一、主轴（双向互锁）

**镐子锁采集，台子锁制造**，两道门都得过：

- 有上档镐才能挖出下档矿（木镐→石，石镐→铁/铜，铁镐→铀）。
- 有对应时代科技 + 对应等级台子，才能制造该档物品。
- 台子本身是**建筑升级链**（花材料升级），科技只管解锁时代，互锁靠材料卡。

```
徒手（木/果）
 → 木镐（零科技可搓）→ 挖石
 → 木器时代 → 石器时代（均免研究台）
 → 研究台（木10铁4，需石镐挖铁）
 → 铁器时代 → 自动火力 → 蒸汽 → 电气 → 核能跃迁（均需研究台）
```

食物线是**侧支**：保留驯化种田→钓鱼/放牧→食物链整合→收纳物流，只加农田产量/食物增益，**不卡主线**（蒸汽只认自动火力，不认食物链）。

顺序（TECH_ORDER）：woodcraft → stone_age → farming → fishing → husbandry → food_chain → logistics → iron_age → defense → steam → electric → nuclear。注意 iron_age 接 stone_age 而不是 logistics，**主线不经过食物侧支**。

铜矿定位：**只做电气件**（电线/灯/管/电机件），不做镐斧剑，见资源表。

## 三、零科技可建（12 项）

城墙、城墙加固、门、地板、地板加固、火把、篝火、农田、床、工作台、研究台，**+ 木镐/木斧徒手搓**（craft 直搓，无需科技、无需台子，破死锁用）。

其他一切工具/家具/建筑都需要对应时代科技。工作台建筑本身零科技可建，但用它做石器需要石器时代科技。

## 四、研究规则（代码）

1. 木器/石器两节点**免研究台**（`NO_BENCH_TECH = {woodcraft, stone_age}`），其余一律要先建成研究台（`has_research_bench()`）。
2. 材料现付，点科技时立刻扣（`begin_research`）。
3. 一次一项，殖民者在研究台投工时推进（`contribute_research`，食物侧支也一样，只是增益另算）。
4. 食物侧支增益落地前先只记账（产量系数），数值生效可后补，不卡主线贯通。
