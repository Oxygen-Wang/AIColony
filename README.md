# AIColony

AIColony is a Godot-based AI colony simulation project.

## Project

The main Godot project lives in `AIColonyDemo/`.

## Local Setup

- Open `AIColonyDemo/project.godot` with Godot.
- Keep API keys and local credentials in `.env`.
- Use `.env.example` as the safe template for local environment variables.

## Version Control

- Godot cache, local AI settings, secrets, and tooling folders are ignored.
- Binary game assets are configured for Git LFS.
- Local planning materials and AI workspace rules are kept off GitHub.
