- 按项目约定统一 `script/`、`scene/`、`image/`、`audio/`、`test/`，修正场景和资源引用。
- 迁入 ColonySim 人物、怪物、物件、头像、系统图集、自动图块及音频；保留原始授权文件。逐文件来源与校验值见 `MIGRATION_MANIFEST.json`。
- 复用旧版人物角色块映射和物件图块区域，修正六人选帧；树、石、铁矿、墙、门、床、火把、炮塔使用图集。新科幻建筑继续使用原有程序图形。
- 移植并适配旧项目的 JSON 配平抢救，解析失败按原始玩家输入兜底。修正自动选址提示与手工蓝图玩法冲突。

- 新增当前目标、建造材料提示、人物能力说明、快捷指令、历史记录、返回基地与暂停键；输入文字时不会带动相机。

## 验证

Godot 4.7.2 下 `test/regression.tscn` 完成 35 项离线检查，覆盖指令、图集范围、蓝图取消、紧急命令、迁移状态与继续、实际采集及建造/种植/收割/烹饪链路。另运行约 34 秒的现有加速模拟，看到资源入库、制作装备、野兽战斗与撤退。

1920×1080 实际渲染截图检查中文、人物、图块、顶部操作栏与聊天区。运行环境出现系统证书读取及用户日志目录写入提示；这些与本轮脚本执行无关，联网 API 未做实际请求验收。

## 尚未实现
