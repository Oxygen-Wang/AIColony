# AI Life：星神远征

用文字指挥六名殖民者，在地图上亲手规划基地；通过采集、生产、防卫与研究建成方舟核心，携带基地前往下一颗星球。

用 Godot 4.7.2 打开 `project.godot`，运行主场景。没有 API Key 也可玩，开始界面可选择难度与配置模型。

## 开始玩

1. 输入“抽抽砍5棵树，七海采3块石头”。
2. 顶部建造栏只显示图案，悬停可看名称、材料消耗与具体说明；选中后在地图上规划，殖民者会自动施工。
3. 采集铁矿、建研究台，完成物流、火力、电力和星海跃迁研究。
4. 建成方舟核心并清除野兽后，点击“方舟跃迁”。结算可选择继续殖民新星球。

已建农田会自动补种、收割，食物不足时自动烹饪。建筑、库存、科技、施工计划、作物和幸存者状态会随迁移保留。当前版本迁移整张地图内的人工建设，尚未限定连通地基范围。

## 操作

| 操作 | 输入 |
|---|---|
| 指挥 | 底部文字框 Enter 发送，或点快捷指令 |
| 历史 | 输入框内 ↑ / ↓ |
| 相机 | WASD / 方向键，滚轮缩放，Home 返回基地 |
| 规划单格 | 选中图案后左键点一下 |
| 拉连续城墙 | Shift + 左键拖动，按 L 形补满中间跳过的格子，不会留下缺口 |
| 拉方形一片 | Ctrl + 左键拖出矩形，松开一次性铺满 |
| 旋转朝向 | R，虚影与建成后的建筑都按这个朝向 |
| 撤销 | 右键点掉该格的计划 |
| 人物 | 点击人物或顶部人物卡查看状态 |
| 暂停 | 空格或顶部暂停按钮，×1 / ×2 / ×4 调速 |
| 输入焦点 | Enter 进入输入，Esc 退出输入 |

地板是基底：铺好地板后还能在地板上继续规划其他建筑，建筑被打掉后地板原地恢复。城墙与地板都能规划“加固”升级，加固计划的虚影会放大一圈叠在已有建筑上。

“所有人迎击野兽”“大家撤回基地”会中断旧工作。建造命令只处理玩家已放置的规划，AI 不自动选址。

## 目录与来源

- `script/` 游戏逻辑；`scene/` 场景。
- `image/` 精灵与图块；`audio/` 迁入的音频资源，目前尚未全面接线。
- `test/` 离线回归场景。
- [整合策划](../策划/08-星神远征整合策划.md)、[整合记录](docs/INTEGRATION_REPORT.md)、[迁移清单](docs/MIGRATION_MANIFEST.json)。

本项目独立引用自己的资源。ColonySim 的角色块映射、物件贴图与 JSON 抢救已移植；其他旧版实现保留在工作区本地备份中。

## 开发验证

以 Godot 控制台程序运行：

```text
--headless --path AIColonyDemo res://test/regression.tscn -- --offline
--headless --path AIColonyDemo -- --selftest --offline
--path AIColonyDemo -- --autostart --offline --shot
```

第一项为 60 项带断言回归，第二项为约 34 秒加速模拟，第三项实际渲染截图到 `shot.png`。离线标记不清除已保存的 API 配置。联网接口需要单独验收。

新增脚本后先跑一次 `--headless --import --path AIColonyDemo` 刷新全局类名缓存，headless 回归才能识别新的 `class_name`。
